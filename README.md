# TARGET DESTROY ⌖ — دليل التنزيل

تطبيق حمد الشخصي للتمرين. كل البيانات تنحفظ على جهازك (localStorage) — ما يحتاج إنترنت بعد التحميل، وما يحتاج حساب.

## الملفات
- `index.html` — التطبيق كامل
- `manifest.json` — إعدادات التثبيت
- `icon.png` — أيقونة التطبيق

---

## تنزيله على تلفونك (طريقتين)

### الطريقة الأسرع (بدون GitHub) — للتجربة
1. حمّل الملفات الثلاثة على تلفونك
2. افتح `index.html` بمتصفح Safari
> ملاحظة: بعض المتصفحات ما تشغل ملف محلي زين — لو صار، استخدم طريقة GitHub تحت.

### الطريقة الكاملة — GitHub Pages (يصير رابط دائم + يتثبت كتطبيق)

**1. سوّ حساب GitHub** (مجاني) على github.com

**2. سوّ Repository جديد:**
- اضغط **+** فوق يمين → **New repository**
- الاسم: `target-destroy`
- خليه **Public** → **Create repository**

**3. ارفع الملفات:**
- اضغط **uploading an existing file**
- اسحب `index.html` و `manifest.json` و `icon.png`
- **Commit changes**

**4. فعّل الموقع:**
- **Settings** → **Pages** (القائمة اليسار)
- تحت Branch اختر **main** → **Save**
- انتظر دقيقة، بيطلع رابط مثل:
  `https://USERNAME.github.io/target-destroy/`

**5. ثبّته كتطبيق على الآيفون:**
- افتح الرابط في **Safari**
- اضغط زر **المشاركة** (المربع مع السهم)
- **Add to Home Screen** (أضف إلى الشاشة الرئيسية)
- بتطلع أيقونة ⌖ على شاشتك مثل أي تطبيق

---

## تشاركه مع صديقك
اعطه نفس الرابط — يفتحه بسفاري ويسوي Add to Home Screen. عنده نفس البرنامج، وكل واحد بياناته على جهازه.

## تنبيه
- البيانات محفوظة بالمتصفح — لا تمسح بيانات Safari وإلا تروح
- التذكيرات تطلع لما تفتح التطبيق (مش إشعارات تلقائية)
- كرت الإبرة للاستخدام مع علاج موصوف من المستشفى
